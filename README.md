# 🎯 AI-Based Online Proctored Exam System

## 📌 Overview

This project is an **AI-Based Online Proctored Exam System** developed using Machine Learning techniques. The main objective of this project is to work with multiple datasets and apply data processing and analysis methods that can support monitoring in an online examination environment.

The project is implemented using Python in **Google Colab / Jupyter Notebook**, where different datasets are processed and analyzed to generate meaningful outputs.

---

## 🎯 Objectives

* To understand and work with multiple real-world datasets
* To perform data preprocessing and analysis
* To apply Machine Learning techniques for data handling
* To generate insights using visualization
* To simulate a basic structure of an AI-based monitoring system

---

## 📊 Datasets Used

The project uses multiple datasets stored inside the `datasets` folder:

* **Face Detection.v27i.yolo26**

  * Contains data related to face detection
  * Used for understanding image-based datasets

* **Students Dataset **

  * Structured dataset
  * Used for performing ML operations and analysis

* **UrbanSound8K Dataset **

  * Contains sound-related data
  * Used for audio-based data analysis

* **Online Proctoring System **

  * Contains main project-related files
  * Used as the core dataset for implementation

## ⚙️ Methodology

The project follows a basic Machine Learning workflow:

1. **Data Collection**

   * Multiple datasets are used from different domains

2. **Data Preprocessing**

   * Cleaning and organizing data
   * Handling structured datasets (Excel files)

3. **Data Analysis**

   * Applying ML techniques
   * Extracting useful information

4. **Visualization**

   * Graphs and plots created using Matplotlib
   * Helps in better understanding of data

## ▶️ How to Run

1. Open the project in **Google Colab or Jupyter Notebook**
